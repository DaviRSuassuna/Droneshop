### O que entregar

Drones têm unidades com `numeroSerie`, `registroAnac` e `validadeGarantia`. Na expedição, item com quantidade N recebe N unidades distintas do mesmo produto. Pedido com drone não vai a ENVIADO sem séries para todos os drones (RN12). `validadeGarantia` = data da expedição + `garantiaMeses` do produto.

### Contrato de API

Convenções gerais (paginação, `idXxx`, status `{id, nome}`, erros Problem) em [`docs/API.md`](https://github.com/DaviRSuassuna/droneshop/blob/develop/docs/API.md). Rotas do admin exigem token de administrador com permissão no módulo (#4, #5); rotas `/conta` exigem cliente logado.

```
GET /status-unidade -> 200 [ DISPONIVEL=1, RESERVADA=2, VENDIDA=3, DEVOLVIDA=4 ]

POST /unidades { "idProduto": 31, "numeroSerie": "FX2P-0001", "registroAnac": "" } -> 200
   { "id","produto":{...},"numeroSerie","registroAnac","status":{"id":1,...},"validadeGarantia":null,"itemPedido":null }
-> 400 errors[].field = "numeroSerie"  repetido
-> 400 errors[].field = "idProduto"   produto acessório ou kit
GET /unidades?serie=&idProduto=&idStatus=&page=&pageSize= -> 200 PageResponse

POST /pedidos/{id}/itens/{idItem}/unidades { "idsUnidades": [7, 8] } -> 204
-> 400 errors[].field = "idsUnidades"  quantidade diferente da do item, unidade repetida,
                                       de outro produto ou não DISPONIVEL
   unidades viram VENDIDA, com validadeGarantia calculada
PATCH /pedidos/{id}/status para ENVIADO com drone sem série -> 409 (RN12)
```
