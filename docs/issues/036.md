### O que entregar

Estorno ligado ao pagamento, com valor e motivo; chama `POST /v1/payments/{id}/refunds { amount }` no Mercado Pago (falso no teste) e atualiza o status para ESTORNADO (soma = valor) ou ESTORNADO_PARCIAL.

### Contrato de API

Convenções gerais (paginação, `idXxx`, status `{id, nome}`, erros Problem) em [`docs/API.md`](https://github.com/DaviRSuassuna/droneshop/blob/develop/docs/API.md). Rotas do admin exigem token de administrador com permissão no módulo (#4, #5); rotas `/conta` exigem cliente logado.

```
POST /pagamentos/{id}/estorno { "valor": 100.00, "motivo": "Devolução parcial" } -> 200
   { "id","valor","motivo","dataCadastro","pagamento":{"id","status":{"nome":"ESTORNADO_PARCIAL"}} }
-> 400 errors[].field = "valor"  menor ou igual a 0, ou soma dos estornos acima do valor pago
-> 409 pagamento que não está APROVADO nem ESTORNADO_PARCIAL
GET /pagamentos/{id}/estornos -> 200 [ ... ]
```
