### O que entregar

Promoção com `escopo` (PRODUTO, CARRINHO, FRETE), vigência, percentual **ou** valor, valor mínimo de carrinho. Escopo produto liga N:N com variantes. A situação (agendada, vigente, encerrada, inativa) é derivada das datas e de `ativa`. Promoção já aplicada em pedido não se exclui (D28).

### Contrato de API

Convenções gerais (paginação, `idXxx`, status `{id, nome}`, erros Problem) em [`docs/API.md`](https://github.com/DaviRSuassuna/droneshop/blob/develop/docs/API.md). Rotas do admin exigem token de administrador com permissão no módulo (#4, #5); rotas `/conta` exigem cliente logado.

```
GET /escopos-promocao -> 200 [ PRODUTO=1, CARRINHO=2, FRETE=3 ]

POST /promocoes
{ "nome": "Semana do drone", "idEscopo": 1, "dataInicio": "2026-11-01T00:00:00",
  "dataFim": "2026-11-08T23:59:59", "percentualDesconto": 10, "valorDesconto": null,
  "valorMinimoCarrinho": null, "ativa": true, "idsVariantes": [31, 32] }
-> 200 { "id": 3, "escopo": {...}, ..., "situacao": "AGENDADA", "variantes": [ {"id","sku","nome"} ] }
-> 400 errors[].field = "percentualDesconto"  os dois informados, nenhum, ou fora de 0 a 100
-> 400 errors[].field = "dataFim"             antes de dataInicio
-> 400 errors[].field = "idsVariantes"        escopo PRODUTO sem variantes
-> 400 errors[].field = "valorMinimoCarrinho" escopo CARRINHO sem mínimo

GET /promocoes?situacao=VIGENTE|AGENDADA|ENCERRADA&page=&pageSize= -> 200 PageResponse
GET /promocoes/{id} -> 200 | 404 ;  PUT -> 204 | 404 ;  DELETE -> 204 | 404 | 409

GET /loja/ofertas (público) -> 200 [ { "produto": {...}, "variante": {...}, "precoDe", "precoPor",
                                       "promocao": {"id","nome","dataFim"} } ]
   só promoções vigentes e ativas de escopo PRODUTO, só produtos ATIVO
```
