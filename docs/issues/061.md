### O que entregar

Rotas que as telas do admin pedem e não tinham issue (API.md, seção "Telas que pedem rota sem issue"): contagem de produtos nas listagens, ações em lote de produto, reordenação de categorias, exportação CSV e etiqueta de envio.

### Contrato de API

Convenções gerais (paginação, `idXxx`, status `{id, nome}`, erros Problem) em [`docs/API.md`](https://github.com/DaviRSuassuna/droneshop/blob/develop/docs/API.md). Rotas do admin exigem token de administrador com permissão no módulo (#4, #5); rotas `/conta` exigem cliente logado.

```
GET /marcas, /categorias, /subcategorias, /fornecedores (e consultas individuais): cada item ganha "quantidadeProdutos"
   Contagem de todos os produtos vinculados, de qualquer tipo/status; categoria soma suas subcategorias.
GET /marcas?busca=&idStatus=&paisOrigem=
GET /fornecedores?busca=&idStatus=&uf=
   Os mesmos filtros se aplicam ao CSV. Filtros vazios são ignorados.

PATCH /produtos/lote { "ids": [10, 11], "acao": "ATIVAR"|"INATIVAR"|"MOVER_SUBCATEGORIA"|"REAJUSTAR_PRECO",
                       "idSubcategoria": 3, "percentual": 5.0 }
-> 200 { "processados": 2, "falhas": [ { "id": 11, "motivo": "..." } ] }
   ATIVAR e INATIVAR respeitam as mesmas validações do cadastro (D28); REAJUSTAR_PRECO muda o preço de cada produto selecionado
   Transação por produto: falha de um item não desfaz os demais. Id repetido é processado uma vez.
   MOVER_SUBCATEGORIA exige idSubcategoria e respeita o tipo da categoria (D39; kit aceita qualquer tipo).
   REAJUSTAR_PRECO exige percentual, arredonda para duas casas e não aceita preço final <= 0.
   Estoque físico não muda em nenhuma ação. Lote vazio ou ação desconhecida: 400 Problem.

PATCH /categorias/ordem { "ids": [3, 1, 2] } -> 204   (ordemExibicao = posição a partir de 1)
   Id repetido: 400 errors[].field = "ids"; inexistente: 404; nenhuma alteração parcial.

GET /marcas/exportar, /fornecedores/exportar, /produtos/exportar, /estoque/exportar, /pedidos/exportar
   (mesmos filtros da listagem) -> 200 text/csv; separador ";", UTF-8 com BOM, cabeçalho na 1ª linha

GET /pedidos/{id}/etiqueta -> 200 application/pdf (remetente da configuração, destinatário congelado)
-> 409 pedido sem enderecoEntrega congelado
   PDF local de estudo, sem compra de frete ou postagem; não exige transportadora/rastreio (#30/#31).
```
