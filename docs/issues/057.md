## Contexto
Montar a esteira de CI/CD do projeto: testes ligados às issues, CI que bloqueia merge e protótipo publicado. Junto, simplificar o fluxo de branches e de revisão de PR, revisar todas as issues contra o PRD e as decisões novas e escrever os testes de cada uma. Deploy fica numa issue própria.

## Escopo

### Fluxo de branches e revisão
- [x] Remover `criar-branch-da-issue.yml`; branch de issue passa a ser criada pelo botão "Create a branch" da issue
- [x] Remover `politica-de-branches.yml` (sem validação de nome de branch, de origem ou de `Closes #N`)
- [x] Remover `CODEOWNERS` e `CONTRIBUTING.md` (e referências a eles)
- [x] Rulesets (`develop.json`, `main.json`): 1 aprovação de qualquer colaborador com escrita, sem exigir Code Owner; autor não aprova o próprio PR; bypass de admin mantido; checks obrigatórios passam a ser os de CI
