### O que entregar

Unidade de venda do catálogo. Todo produto ATIVO tem 1..* variantes; produto sem opções tem uma variante única "Padrão". Guarda SKU, `preco` (preço cheio, D26), `custoAquisicao`, `estoqueFisico`, `estoqueMinimo`, peso e 3 dimensões da embalagem e `ativa`. As variantes vão no corpo do drone e do acessório (tabela embutida, D13). Esta issue **remove `Produto.preco`** (D26) e atualiza os testes `base` e `issue-8` que o usam.

`estoqueFisico` informado na criação vira o saldo inicial com um movimento ENTRADA (a tabela de movimentos é da #13; até lá, só o saldo). Depois disso, `estoqueFisico` não muda por PUT: só por movimento.

Margem (fecha P2, D26): `margemPercentual = (preco - custoAquisicao) / preco * 100`, com 2 casas, calculada no backend.

### Contrato de API

Convenções gerais (paginação, `idXxx`, status `{id, nome}`, erros Problem) em [`docs/API.md`](https://github.com/DaviRSuassuna/droneshop/blob/develop/docs/API.md). Rotas do admin exigem token de administrador com permissão no módulo (#4, #5); rotas `/conta` exigem cliente logado.

```
POST /drones  (e /acessorios)  { ...produto..., "variantes": [
   { "nome": "Padrão", "sku": "FX2P-STD", "preco": 7999.00, "custoAquisicao": 5200.00,
     "estoqueFisico": 10, "estoqueMinimo": 2, "pesoEmbalagemKg": 1.8,
     "alturaEmbalagemCm": 20, "larguraEmbalagemCm": 30, "comprimentoEmbalagemCm": 25,
     "ativa": true } ] }
-> 200 { ..., "variantes": [ { "id": 31, "nome": "Padrão", "sku": "FX2P-STD", "preco": 7999.00,
         "custoAquisicao": 5200.00, "margemPercentual": 34.99, "estoqueFisico": 10,
         "estoqueMinimo": 2, ..., "ehKit": false, "ativa": true } ] }
-> 400 errors[].field = "variantes[0].sku"            SKU repetido (em qualquer produto)
-> 400 errors[].field = "variantes"                   produto ATIVO sem variante
-> 400 errors[].field = "variantes[0].pesoEmbalagemKg" variante ativa de produto ATIVO sem peso/dimensões (RN18)
-> 400 errors[].field = "variantes[0].preco"          ATIVO sem preço, ou preço <= 0
   Produto em RASCUNHO aceita variante incompleta (D28)

PUT /drones/{id}  com "variantes": variante com "id" altera; sem "id" cria; a que sumiu da lista
                  é excluída (ou 409 se já tem pedido/reserva, D28). estoqueFisico do PUT é ignorado.

GET /variantes?busca=&ativa=&page=&pageSize=
-> 200 PageResponse de { "id", "sku", "nome", "preco", "estoqueFisico", "ehKit",
                         "produto": {"id","nome","tipo"} }   busca por SKU, nome da variante ou do produto
GET /variantes/{id}  -> 200 | 404
PUT /variantes/{id}  (mesmos campos da variante, sem estoqueFisico) -> 204 | 404

Produto deixa de ter "preco" no corpo e na resposta.
```
