### O que entregar

Cotação expressa/padrão pelo agregador (`FreteClient`, `quarkus.rest-client.frete.url`) usando peso e dimensões da embalagem dos produtos (kit: derivados, D16); `RegraFrete` para retirada no showroom e como fallback. `Entrega` congela custo, prazo, transportadora e origem do cálculo. Toda chamada ao agregador é logada; falha é log de integração (RNF10). No `%test`, `FreteFalso` (D34): CEP de destino começando com `99` simula agregador fora do ar.

API usada do agregador (é o que o falso imita):
`POST /api/v2/me/shipment/calculate { from:{postal_code}, to:{postal_code}, package:{weight,width,height,length} }` -> `[ { id, name, price, delivery_time, company:{name} } ]`. O serviço mais barato vira PADRAO e o mais rápido vira EXPRESSA; `name` vai para `codigoServicoTransportadora` e `company.name` para `transportadora`. O pacote soma o peso de todas as unidades. A carga cria uma `RegraFrete` para cada modalidade (fallback de EXPRESSA e PADRAO, e a retirada).

### Contrato de API

Convenções gerais (paginação, `idXxx`, status `{id, nome}`, erros Problem) em [`docs/API.md`](https://github.com/DaviRSuassuna/droneshop/blob/develop/docs/API.md). Rotas do admin exigem token de administrador com permissão no módulo (#4, #5); rotas `/conta` exigem cliente logado.

```
GET /modalidades-entrega -> 200 [ EXPRESSA=1, PADRAO=2, RETIRADA_SHOWROOM=3 ]
GET /origens-calculo-frete -> 200 [ INTEGRACAO_AGREGADOR=1, REGRA_FRETE=2 ]

POST /frete/cotacao   (público)
{ "cep": "77001000", "itens": [ { "idProduto": 31, "quantidade": 1 } ] }
 ou { "cep": "77001000" } com header X-Carrinho-Token
-> 200 [ { "modalidade": {...}, "origemCalculo": {...}, "transportadora": "Correios",
           "codigoServicoTransportadora": "PAC", "custo": 39.90, "prazoDias": 6 } ]
   sempre inclui RETIRADA_SHOWROOM (RegraFrete); agregador fora -> EXPRESSA/PADRAO vêm da RegraFrete
-> 400 errors[].field = "cep"   sem 8 dígitos

CRUD /admin/regras-frete  { "idModalidade", "custoFixo", "prazoDias", "cepOrigem" } (admin)
Pedido criado congela a cotação escolhida em "entrega" (RN07)
```
