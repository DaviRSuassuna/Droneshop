### O que entregar

Cupom percentual ou valor fixo, vigência, valor mínimo, limite total e por cliente, restrição N:N por categoria, marca e variante. Só o cadastro e as telas do admin; a aplicação no carrinho é a #25. Código guardado em maiúsculas e único sem diferenciar maiúsculas. Cupom já usado não se exclui (D28).

### Contrato de API

Convenções gerais (paginação, `idXxx`, status `{id, nome}`, erros Problem) em [`docs/API.md`](https://github.com/DaviRSuassuna/droneshop/blob/develop/docs/API.md). Rotas do admin exigem token de administrador com permissão no módulo (#4, #5); rotas `/conta` exigem cliente logado.

```
GET /tipos-desconto-cupom -> 200 [ PERCENTUAL=1, VALOR_FIXO=2 ]

POST /cupons
{ "codigo": "bemvindo10", "idTipoDesconto": 1, "valor": 10, "dataInicio": "...", "dataFim": "...",
  "valorMinimo": 200, "limiteTotalUso": 100, "limitePorCliente": 1,
  "idsCategorias": [], "idsMarcas": [], "idsVariantes": [] }
-> 200 { "id": 4, "codigo": "BEMVINDO10", "tipoDesconto": {...}, ..., "situacao": "VIGENTE",
         "usos": 0, "categorias": [], "marcas": [], "variantes": [] }
-> 400 errors[].field = "codigo"  repetido (BEMVINDO10 = bemvindo10) ou com espaço
-> 400 errors[].field = "valor"   percentual fora de 0 a 100, ou valor <= 0
-> 400 errors[].field = "dataFim" antes de dataInicio
-> 400 errors[].field = "limitePorCliente"  maior que limiteTotalUso

GET /cupons?situacao=&codigo=&page=&pageSize= -> 200 PageResponse
GET/PUT/DELETE /cupons/{id} -> 200/204 | 404 ; DELETE de cupom usado -> 409 (D28)
GET /cupons/{id}/usos -> 200 PageResponse de { "pedido": {"id"}, "cliente": {"id","nome"}, "dataUso" }
```
