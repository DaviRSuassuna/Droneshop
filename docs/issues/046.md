### O que entregar

Consentimento datado e versionado por tipo (`TERMOS_USO`, `POLITICA_PRIVACIDADE`, `MARKETING`). Criar conta exige aceitar termos e política na versão vigente. Exclusão anonimiza dados pessoais (nome "Cliente removido", e-mail `removido-<id>@aeria.invalid`, documento e telefone nulos, endereços apagados, sessões revogadas) preservando pedidos.

### Contrato de API

Convenções gerais (paginação, `idXxx`, status `{id, nome}`, erros Problem) em [`docs/API.md`](https://github.com/DaviRSuassuna/droneshop/blob/develop/docs/API.md). Rotas do admin exigem token de administrador com permissão no módulo (#4, #5); rotas `/conta` exigem cliente logado.

```
GET /loja/termos -> 200 [ { "tipo":"TERMOS_USO","versao":"2026-10" } ... ]
POST /clientes (#19) passa a exigir "consentimentos": [ {"tipo":"TERMOS_USO","versao":"2026-10"},
                                                      {"tipo":"POLITICA_PRIVACIDADE","versao":"2026-10"} ]
-> 400 errors[].field = "consentimentos"  faltou um obrigatório ou versão antiga
GET /conta/consentimentos -> 200 [ { "tipo","versao","dataConsentimento" } ]
POST /conta/consentimentos { "tipo":"MARKETING","versao":"2026-10" } -> 204
POST /conta/exclusao { "senha": "..." } -> 204 ; login seguinte -> 401
Pedidos do cliente continuam íntegros (itens, valores, endereço congelado)
```
