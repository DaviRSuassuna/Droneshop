### O que entregar

Acrescentar a `Produto`: `descricao`, `slug`, `metaTitle`, `metaDescription`, `tags`, `garantiaMeses`, `dataLancamento`. `preco` **continua** no produto até a #9 (D26). `garantiaMeses` usa como padrão `ConfiguracaoLoja.prazoGarantiaDias / 30`, arredondado para cima. Rascunho aceita campos vazios (D28); slug gerado como em marca.

### Contrato de API

Convenções gerais (paginação, `idXxx`, status `{id, nome}`, erros Problem) em [`docs/API.md`](https://github.com/DaviRSuassuna/droneshop/blob/develop/docs/API.md). Rotas do admin exigem token de administrador com permissão no módulo (#4, #5); rotas `/conta` exigem cliente logado.

```
POST /produtos   (o corpo atual, mais os campos novos; muda para /drones e /acessorios na #8)
{ ...corpo atual..., "descricao": "Texto longo", "slug": "", "metaTitle": "Falcon X2",
  "metaDescription": "Drone ...", "tags": "fpv,4k", "garantiaMeses": null,
  "dataLancamento": "2026-03-01" }
-> 200 { ..., "slug": "falcon-x2-pro", "garantiaMeses": 13, "dataLancamento": "2026-03-01" }
   slug vazio -> gerado do nome sem acento; slug informado -> normalizado
   garantiaMeses vazio -> padrão da configuração (365 dias -> 13 meses)
-> 400 errors[].field = "slug"            slug de outro produto
-> 400 errors[].field = "metaTitle"       mais de 70 caracteres
-> 400 errors[].field = "metaDescription" mais de 160 caracteres
-> 400 errors[].field = "garantiaMeses"   menor que 0

POST /produtos com idStatus = 1 (RASCUNHO) e só o status -> 200 (D28)

GET /produtos/slug/{slug}  -> 200 | 404

RN17: produto em RASCUNHO nunca aparece em /loja (a vitrine é a #21)
```
