### O que entregar

Lista 0..1 por cliente, criada no primeiro item; itens por produto (D40).

### Contrato de API

Convenções gerais (paginação, `idXxx`, status `{id, nome}`, erros Problem) em [`docs/API.md`](https://github.com/DaviRSuassuna/droneshop/blob/develop/docs/API.md). Rotas do admin exigem token de administrador com permissão no módulo (#4, #5); rotas `/conta` exigem cliente logado.

```
GET /conta/desejos -> 200 [ { "produto": {"id","nome","sku","slug","preco","disponivel"},
                                  "produto": {"id","nome","slug"}, "adicionadoEm" } ]
POST /conta/desejos { "idProduto": 31 } -> 204   (repetir não duplica: continua 204)
-> 400 errors[].field = "idProduto"   inexistente
DELETE /conta/desejos/{idProduto} -> 204 | 404
Sem token -> 401
```
