### O que entregar

Relação N:N `Acessorio` -> `Produto`, gravada pelo cadastro do acessório e visível nos dois lados (D17). Alimenta "acessórios compatíveis" na página do produto. A rota pública da vitrine (`GET /loja/produtos/{slug}/compativeis`) fica na #21, para a Fase 1 ter só o painel administrativo.

### Contrato de API

Convenções gerais (paginação, `idXxx`, status `{id, nome}`, erros Problem) em [`docs/API.md`](https://github.com/DaviRSuassuna/droneshop/blob/develop/docs/API.md). Rotas do admin exigem token de administrador com permissão no módulo (#4, #5); rotas `/conta` exigem cliente logado.

```
POST/PUT /acessorios  { ..., "idsCompativeis": [10, 12] }
-> resposta do acessório: "compativeis": [ {"id":10,"nome":"Falcon X2 Pro","tipo":{...}} ]
-> 400 errors[].field = "idsCompativeis"   id inexistente ou o próprio acessório

GET /produtos/{id}  (drone ou acessório) traz também
   "acessoriosCompativeis": [ {"id":11,"nome":"Bateria 5000 mAh"} ]   (lado recíproco)
```
