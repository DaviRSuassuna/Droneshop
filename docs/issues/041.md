### O que entregar

Registro de entidade, ação, campo, valor anterior/novo, autor, IP e data para criação, atualização, exclusão, login e mudança de status. Uma linha por campo alterado; valores gravados como texto (`toString`, ex.: `1200.00`). Campos de dado pessoal (documento, telefone, e-mail, senha, endereço, token) nunca vão para o log: aparecem como `***` (RNF03).

### Contrato de API

Convenções gerais (paginação, `idXxx`, status `{id, nome}`, erros Problem) em [`docs/API.md`](https://github.com/DaviRSuassuna/droneshop/blob/develop/docs/API.md). Rotas do admin exigem token de administrador com permissão no módulo (#4, #5); rotas `/conta` exigem cliente logado.

```
GET /acoes-auditoria -> 200 [ CRIACAO=1, ATUALIZACAO=2, EXCLUSAO=3, LOGIN=4, MUDANCA_STATUS=5 ]
GET /admin/auditoria?entidade=Produto&entidadeId=31&idAcao=&idUsuario=&page=&pageSize=  (só ADMIN)
-> 200 PageResponse de { "acao","entidade","entidadeId","campo","valorAnterior","valorNovo",
                         "autor":{"id","nome"},"ip","dataHora" }
Sempre auditado: preço do produto, movimento de estoque, status de pedido, login no admin
```
