### O que entregar

Comparar 2 a 4 drones ATIVO lado a lado pelas specs fixas (D14), com as diferenças marcadas pelo backend.

### Contrato de API

Convenções gerais (paginação, `idXxx`, status `{id, nome}`, erros Problem) em [`docs/API.md`](https://github.com/DaviRSuassuna/droneshop/blob/develop/docs/API.md). Rotas do admin exigem token de administrador com permissão no módulo (#4, #5); rotas `/conta` exigem cliente logado.

```
GET /loja/comparar?ids=10,12
-> 200 { "produtos": [ { "id","nome","slug","precoMinimo" } ],
         "specs": [ { "campo":"autonomiaMinutos","rotulo":"Autonomia (min)",
                      "valores":[46,31],"diferente":true,"melhor":0 } ] }
   "melhor" = índice do maior valor em autonomia, alcance, velocidade, resolução e bateria; null nos demais
-> 400 errors[].field = "ids"  menos de 2, mais de 4, acessório, inexistente ou não ATIVO
```
