### O que entregar

Comparar 2 a 4 drones ATIVO lado a lado pelas specs fixas (D14), com as diferenças marcadas pelo backend. Na página do produto, a tabela abre com as versões do grupo (D40) e o cliente pode acrescentar outro drone do catálogo, até 4. Kit entra com as specs do drone que ele contém e com a lista de itens extras.

### Contrato de API

Convenções gerais (paginação, `idXxx`, status `{id, nome}`, erros Problem) em [`docs/API.md`](https://github.com/DaviRSuassuna/droneshop/blob/develop/docs/API.md). Rotas do admin exigem token de administrador com permissão no módulo (#4, #5); rotas `/conta` exigem cliente logado.

```
GET /loja/comparar?grupo=falcon-x2           versões ATIVO do grupo (D40)
GET /loja/comparar?grupo=falcon-x2&ids=15     versões do grupo + outro drone
GET /loja/comparar?ids=10,12
-> 200 { "produtos": [ { "id","nome","slug","preco","nota","totalAvaliacoes","doGrupo","itensExtras" } ],
         "specs": [ { "campo":"autonomiaMinutos","rotulo":"Autonomia (min)",
                      "valores":[46,31],"diferente":true,"melhor":0 } ] }
   "melhor" = índice do maior valor em autonomia, alcance, velocidade, resolução e bateria; null nos demais
-> 400 errors[].field = "ids"  menos de 2 ou mais de 4 no total, acessório, kit sem drone, inexistente ou não ATIVO
-> 404 grupo inexistente ou inativo
```
