### O que entregar

Nota (1 a 5) e comentário por produto; `compraVerificada` automática quando o cliente tem `ItemPedido` ENTREGUE do produto (RN04). Publicação só após APROVADA (RN05). Uma avaliação por cliente e produto.

### Contrato de API

Convenções gerais (paginação, `idXxx`, status `{id, nome}`, erros Problem) em [`docs/API.md`](https://github.com/DaviRSuassuna/droneshop/blob/develop/docs/API.md). Rotas do admin exigem token de administrador com permissão no módulo (#4, #5); rotas `/conta` exigem cliente logado.

```
GET /status-moderacao -> 200 [ PENDENTE=1, APROVADA=2, REJEITADA=3 ]
POST /loja/produtos/{slug}/avaliacoes (cliente) { "nota": 5, "comentario": "..." }
-> 200 { "id","nota","comentario","compraVerificada": true|false,"status":{"nome":"PENDENTE"} }
-> 400 errors[].field = "nota"  fora de 1 a 5
-> 409 cliente já avaliou o produto
GET /loja/produtos/{slug}/avaliacoes -> 200 { "media": 4.5, "quantidade": 2, "itens": [ só APROVADA ] }
GET /admin/avaliacoes?idStatus=1 ; PATCH /admin/avaliacoes/{id} { "idStatus": 2 } -> 204
```
