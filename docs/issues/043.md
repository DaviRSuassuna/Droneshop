### O que entregar

`GET /loja/busca` busca produtos ATIVO por nome, modelo, marca e tags, sem diferenciar maiúsculas **nem acentos** (D23), e grava o termo normalizado (minúsculo, sem acento, espaços colapsados) com a quantidade de resultados. Relatório no admin agrupa por termo.

### Contrato de API

Convenções gerais (paginação, `idXxx`, status `{id, nome}`, erros Problem) em [`docs/API.md`](https://github.com/DaviRSuassuna/droneshop/blob/develop/docs/API.md). Rotas do admin exigem token de administrador com permissão no módulo (#4, #5); rotas `/conta` exigem cliente logado.

```
GET /loja/busca?q=fálcon&page=&pageSize= -> 200 PageResponse (mesmo item de /loja/produtos)
   q com menos de 2 caracteres -> 400 field "q" (não grava)
GET /admin/termos-buscados?semResultado=true&dataInicio=&dataFim=&page=&pageSize=
-> 200 PageResponse de { "termo":"falcon","buscas": 12,"ultimaQuantidadeResultados": 0,"ultimaBusca" }
   ordenado por buscas, maior primeiro
```

Barra de busca do storefront (index.html); relatório no admin segue o padrão de listagem
