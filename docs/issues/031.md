### O que entregar

`codigoRastreio` na entrega e eventos com descrição, localização e data/hora, lançados pelo admin.

### Contrato de API

Convenções gerais (paginação, `idXxx`, status `{id, nome}`, erros Problem) em [`docs/API.md`](https://github.com/DaviRSuassuna/droneshop/blob/develop/docs/API.md). Rotas do admin exigem token de administrador com permissão no módulo (#4, #5); rotas `/conta` exigem cliente logado.

```
PUT /pedidos/{id}/entrega/codigo-rastreio { "codigoRastreio": "BR123456789BR" } -> 204 (admin)
POST /pedidos/{id}/rastreio { "descricao": "Saiu para entrega", "localizacao": "Palmas/TO",
                              "dataHora": "2026-11-02T08:30:00" } -> 200 evento   (admin)
-> 409 pedido sem entrega ou ainda não ENVIADO
GET /pedidos/{id}/rastreio (admin) e GET /conta/pedidos/{id}/rastreio (dono)
-> 200 { "codigoRastreio", "transportadora", "eventos": [ ... em ordem cronológica ... ] }
```
