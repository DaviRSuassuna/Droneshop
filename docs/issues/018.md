### O que entregar

Tela `dashboard`: pedidos por status, faturamento do período, variantes abaixo do estoque mínimo e últimos pedidos. Tudo calculado no backend. Faturamento = soma de `valorTotal` dos pedidos com status PAGO, SEPARACAO, ENVIADO ou ENTREGUE criados no período.

### Contrato de API

Convenções gerais (paginação, `idXxx`, status `{id, nome}`, erros Problem) em [`docs/API.md`](https://github.com/DaviRSuassuna/droneshop/blob/develop/docs/API.md). Rotas do admin exigem token de administrador com permissão no módulo (#4, #5); rotas `/conta` exigem cliente logado.

```
GET /admin/dashboard?dataInicio=2026-10-01&dataFim=2026-10-31
   (sem datas: últimos 30 dias)
-> 200 { "periodo": { "dataInicio", "dataFim" },
         "faturamento": 12345.60, "quantidadePedidos": 8, "ticketMedio": 1543.20,
         "pedidosPorStatus": [ { "status": {...}, "quantidade": 1 } x 8 ],
         "estoqueBaixo": [ { "variante": {...}, "produto": {...}, "disponivel", "estoqueMinimo" } ],
         "ultimosPedidos": [ { "id", "numero", "cliente", "status", "valorTotal", "dataCadastro" } x até 5 ] }
-> 400 errors[].field = "dataFim"   antes de dataInicio
```
