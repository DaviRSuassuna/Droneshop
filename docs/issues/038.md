### O que entregar

Chamado com protocolo legível (`AER-AAAAMMDD-NNNN`), assunto, pedido opcional, atendente responsável e mensagens. Resposta do atendente põe o chamado EM_ANDAMENTO e dispara `CHAMADO_RESPONDIDO`. Encerrado não recebe mensagem (409).

### Contrato de API

Convenções gerais (paginação, `idXxx`, status `{id, nome}`, erros Problem) em [`docs/API.md`](https://github.com/DaviRSuassuna/droneshop/blob/develop/docs/API.md). Rotas do admin exigem token de administrador com permissão no módulo (#4, #5); rotas `/conta` exigem cliente logado.

```
POST /chamados (cliente logado) { "assunto": "Drone não liga", "idPedido": 9, "mensagem": "..." }
-> 200 { "id","protocolo":"AER-20261102-0001","status":{"id":1,"nome":"ABERTO"},"assunto","pedido":{"id"},
         "mensagens":[ { "tipoAutor":{"nome":"CLIENTE"},"texto","dataCadastro" } ] }
-> 400 errors[].field = "idPedido"  pedido de outro cliente
GET /conta/chamados ; GET /chamados/{id}/mensagens ; POST /chamados/{id}/mensagens { "texto" }
GET /admin/chamados?idStatus= ; POST /admin/chamados/{id}/mensagens { "texto" } (atendente)
PATCH /admin/chamados/{id}/status { "idStatus": 3 } -> 204 | 409
Mensagem em chamado ENCERRADO -> 409
```
