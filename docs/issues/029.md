### O que entregar

Fechamento do carrinho gera o pedido com preço congelado, endereço congelado (D12), `DescontoPedido` por origem (cupom ou promoção) e `UsoCupom` vinculado ao pedido. Pedido CANCELADO libera o uso do cupom (RN13). Promoção de escopo PRODUTO vigente na hora da compra vira `DescontoPedido` de origem PROMOCAO; o item guarda o preço cheio congelado. Também entrega a área "Meus pedidos" do cliente.

### Contrato de API

Convenções gerais (paginação, `idXxx`, status `{id, nome}`, erros Problem) em [`docs/API.md`](https://github.com/DaviRSuassuna/droneshop/blob/develop/docs/API.md). Rotas do admin exigem token de administrador com permissão no módulo (#4, #5); rotas `/conta` exigem cliente logado.

```
(criação: POST /checkout, #26; esta issue acrescenta descontos e uso de cupom)

GET /origens-desconto -> 200 [ CUPOM=1, PROMOCAO=2 ]
GET /conta/pedidos?page=&pageSize= -> 200 PageResponse dos pedidos do cliente
GET /conta/pedidos/{id}
-> 200 { "id","numero","status","itens":[...congelados...],"enderecoEntrega":{...},
         "valorProdutos","valorFrete","valorDesconto","valorTotal",
         "descontos": [ { "origem": {...}, "descricao": "Cupom BEMVINDO10", "valor": 50.00 } ],
         "entrega": {...}, "pagamentos": [...] }
-> 404 pedido de outro cliente
   valorTotal = valorProdutos + valorFrete - valorDesconto
   valorDesconto = soma de descontos[].valor (RN16)
GET /cupons/{id}/usos (admin, #15) passa a listar o uso
```
