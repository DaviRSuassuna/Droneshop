### O que entregar

Fluxo de `checkout.html` até `confirmacao.html`: ao entrar, reserva (#23); escolhe endereço do cliente, modalidade com frete cotado (#30) e método de pagamento; confirma criando o pedido com itens e endereço congelados e a entrega cotada. Descontos, uso de cupom e "Meus pedidos" são da #29. Exige cliente logado.

### Contrato de API

Convenções gerais (paginação, `idXxx`, status `{id, nome}`, erros Problem) em [`docs/API.md`](https://github.com/DaviRSuassuna/droneshop/blob/develop/docs/API.md). Rotas do admin exigem token de administrador com permissão no módulo (#4, #5); rotas `/conta` exigem cliente logado.

```
POST /checkout   (cliente logado + header X-Carrinho-Token)
{ "idEndereco": 5, "idModalidadeEntrega": 2, "codigoServicoTransportadora": "PAC",
  "idMetodoPagamento": 1 }
-> 200 { "id","numero","status":{"id":1,"nome":"PENDENTE"},"itens":[...],"enderecoEntrega":{...},
         "entrega":{...},"valorProdutos","valorFrete","valorDesconto","valorTotal" }
   carrinho vira CONVERTIDO; reservas continuam ATIVA até o pagamento
-> 400 errors[].field = "idEndereco"            endereço de outro cliente
-> 400 errors[].field = "idModalidadeEntrega"   modalidade sem cotação válida
-> 409 carrinho vazio, sem reserva ativa ou já convertido
-> 401 sem login
Frete externo fora do ar não trava: a cotação cai para RegraFrete (RNF05, #30)
```
