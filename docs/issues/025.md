### O que entregar

Cupom fica em `Carrinho.cupomAplicado` até o fechamento, validando vigência, mínimo, limites e restrições (sobre os itens elegíveis). O desconto é recalculado a cada mudança do carrinho; se o carrinho deixar de atender o cupom, ele sai e o carrinho traz o aviso.

### Contrato de API

Convenções gerais (paginação, `idXxx`, status `{id, nome}`, erros Problem) em [`docs/API.md`](https://github.com/DaviRSuassuna/droneshop/blob/develop/docs/API.md). Rotas do admin exigem token de administrador com permissão no módulo (#4, #5); rotas `/conta` exigem cliente logado.

```
POST /carrinho/cupom { "codigo": "bemvindo10" }   (header X-Carrinho-Token)
-> 200 carrinho com "cupom": { "codigo": "BEMVINDO10", "desconto": 50.00 }, "desconto", "total"
-> 400 Problem com errors[] = { "field": "codigo", "message": "texto para o cliente", "motivo": ... } (RN03):
       CUPOM_INEXISTENTE | FORA_DA_VIGENCIA | VALOR_MINIMO_NAO_ATINGIDO |
       LIMITE_TOTAL_ATINGIDO | LIMITE_POR_CLIENTE_ATINGIDO | SEM_ITENS_ELEGIVEIS
   LIMITE_POR_CLIENTE só é checado com cliente logado; sem login, é checado no checkout
DELETE /carrinho/cupom -> 200 carrinho sem cupom, total recalculado
Carrinho que deixa de atender o mínimo: cupom removido e "avisos": ["CUPOM_REMOVIDO_VALOR_MINIMO"]
```
