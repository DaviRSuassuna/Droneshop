### O que entregar

Guarda só `tokenGateway`, `ultimosDigitos`, `bandeira` e `validade`. O número completo nunca chega ao backend: o front tokeniza no SDK do Mercado Pago.

### Contrato de API

Convenções gerais (paginação, `idXxx`, status `{id, nome}`, erros Problem) em [`docs/API.md`](https://github.com/DaviRSuassuna/droneshop/blob/develop/docs/API.md). Rotas do admin exigem token de administrador com permissão no módulo (#4, #5); rotas `/conta` exigem cliente logado.

```
GET /conta/cartoes -> 200 [ { "id", "ultimosDigitos": "4242", "bandeira": "visa",
                                 "validade": "12/30", "padrao": true } ]   (nunca o token)
POST /conta/cartoes { "tokenGateway": "card_tok_x", "ultimosDigitos": "4242",
                      "bandeira": "visa", "validade": "12/30" } -> 200 cartão
-> 400 errors[].field = "ultimosDigitos"  diferente de 4 dígitos
-> 400 errors[].field = "numero"          o corpo trouxe número completo de cartão (RN11)
-> 400 errors[].field = "validade"        vencido ou fora do formato MM/AA
DELETE /conta/cartoes/{id} -> 204 | 404 ; PATCH /conta/cartoes/{id}/padrao -> 204
Pagamento com "idCartaoSalvo" usa o token guardado (#27)
```
