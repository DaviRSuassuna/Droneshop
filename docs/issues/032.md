### O que entregar

`ResendClient` (`quarkus.rest-client.resend.url`). Templates versionados com variáveis `{{nome}}`, editáveis no admin (editar cria nova versão). Notificação guarda texto renderizado e `identificadorProvedor`; webhook do Resend atualiza ENTREGUE/ABERTA/BOUNCE/SPAM. Envio fora da transação de quem disparou: falha vira status FALHA e log de integração, sem derrubar a operação (RNF05, RNF10). No `%test`, `ResendFalso` guarda os e-mails, consultáveis em `GET /resend-falso/emails?para=` (D34).

Templates da carga: `PEDIDO_CONFIRMADO`, `PAGAMENTO_APROVADO`, `PEDIDO_ENVIADO`, `RASTREIO_ATUALIZADO`, `DEVOLUCAO_ATUALIZADA`, `CHAMADO_RESPONDIDO`, `VERIFICAR_EMAIL`, `RECUPERAR_SENHA`, `CARRINHO_ABANDONADO`.

API usada do Resend: `POST /emails { from, to, subject, html }` -> `{ id }`.

### Contrato de API

Convenções gerais (paginação, `idXxx`, status `{id, nome}`, erros Problem) em [`docs/API.md`](https://github.com/DaviRSuassuna/droneshop/blob/develop/docs/API.md). Rotas do admin exigem token de administrador com permissão no módulo (#4, #5); rotas `/conta` exigem cliente logado.

```
GET /admin/templates-email -> 200 [ { "id","codigo","assunto","versao","ativo" } ]
GET /admin/templates-email/{codigo} -> 200 { ..., "corpoTemplate": "Olá {{nome}}...", "variaveis": ["nome","numeroPedido"] }
PUT /admin/templates-email/{codigo} { "assunto", "corpoTemplate" } -> 200 nova versão (versao + 1)
-> 400 errors[].field = "corpoTemplate"  usa variável que o template não oferece

GET /admin/notificacoes?destinatario=&idStatusEnvio=&page=&pageSize= -> 200 PageResponse, mais recente primeiro
   { "id","template":{"codigo"},"categoria","statusEnvio","destinatario":{"email"},"assunto",
     "identificadorProvedor","dataCadastro" }
POST /webhooks/resend { "type": "email.delivered"|"email.opened"|"email.bounced"|"email.complained",
                        "data": { "email_id": "<identificadorProvedor>" } } -> 200

Disparos: pedido criado -> PEDIDO_CONFIRMADO; pagamento aprovado -> PAGAMENTO_APROVADO;
pedido ENVIADO -> PEDIDO_ENVIADO
```
