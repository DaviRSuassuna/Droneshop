### O que entregar

Variante com `ehKit=true` não tem estoque próprio: é composta por outras variantes com quantidade. Disponibilidade derivada = mínimo entre (disponível do componente / quantidade exigida), arredondado para baixo. Peso e dimensões do kit derivados dos componentes (peso somado; dimensões: maior altura e largura, comprimentos somados), com sobrescrita opcional.

### Contrato de API

Convenções gerais (paginação, `idXxx`, status `{id, nome}`, erros Problem) em [`docs/API.md`](https://github.com/DaviRSuassuna/droneshop/blob/develop/docs/API.md). Rotas do admin exigem token de administrador com permissão no módulo (#4, #5); rotas `/conta` exigem cliente logado.

```
Na lista "variantes" do drone/acessório:
{ "nome": "Fly More", "sku": "FX2P-FLY", "preco": 9999.00, "ehKit": true,
  "componentes": [ { "idVariante": 31, "quantidade": 1 }, { "idVariante": 44, "quantidade": 2 } ],
  "pesoEmbalagemKg": null, "alturaEmbalagemCm": null, ... }
-> 200 variante kit: { ..., "ehKit": true, "estoqueFisico": null, "disponivel": 4,
       "componentes": [ { "variante": {"id":31,"sku":..,"nome":..}, "quantidade": 1 } ],
       "pesoEmbalagemKg": 2.6 (derivado), "pesoSobrescrito": false }
-> 400 errors[].field = "variantes[0].estoqueFisico"  kit com estoque informado
-> 400 errors[].field = "variantes[0].componentes"    kit sem componentes, com outro kit,
                                                      ou com ele mesmo
-> 400 errors[].field = "variantes[0].componentes[0].quantidade"  menor que 1

Toda variante (kit ou não) passa a trazer "disponivel" (físico - reservas ativas;
no kit, derivado). GET /variantes/{id} idem.
```
