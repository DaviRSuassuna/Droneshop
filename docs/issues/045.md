### O que entregar

TOTP (RFC 6238, 30 s, 6 dígitos, SHA-1) com `twoFASecret` em Base32; habilitado por usuário. Com 2FA ligado, o login pede o código antes de entregar o token completo.

### Contrato de API

Convenções gerais (paginação, `idXxx`, status `{id, nome}`, erros Problem) em [`docs/API.md`](https://github.com/DaviRSuassuna/droneshop/blob/develop/docs/API.md). Rotas do admin exigem token de administrador com permissão no módulo (#4, #5); rotas `/conta` exigem cliente logado.

```
POST /conta/2fa -> 200 { "secret": "BASE32...", "otpauthUrl": "otpauth://totp/Aeria:..." }   (gera, ainda desligado)
POST /conta/2fa/confirmar { "codigo": "123456" } -> 204 ; liga o 2FA | 400 field "codigo"
DELETE /conta/2fa { "codigo": "123456" } -> 204 ; desliga
Depois de ligado, nenhuma rota devolve o secret; POST /conta/2fa com 2FA ligado -> 409.

POST /auth/login de quem tem 2FA -> 200 { "precisa2fa": true, "tokenTemporario": "...", "token": null }
POST /auth/login/2fa { "tokenTemporario": "...", "codigo": "123456" } -> 200 { "token": "..." } | 401
```
