### O que entregar

Rotas públicas em `/loja`: produtos paginados com filtros por categoria, subcategoria, marca, faixa de preço (sobre o preço da variante) e specs do drone; facetas; página de produto por slug com variantes, specs e mídias. Só produto ATIVO com ao menos uma variante ativa (RN17). Busca por nome sem diferenciar maiúsculas nem acentos.

### Contrato de API

Convenções gerais (paginação, `idXxx`, status `{id, nome}`, erros Problem) em [`docs/API.md`](https://github.com/DaviRSuassuna/droneshop/blob/develop/docs/API.md). Rotas do admin exigem token de administrador com permissão no módulo (#4, #5); rotas `/conta` exigem cliente logado.

```
GET /loja/categorias -> 200 [ { "id","nome","slug","subcategorias":[{"id","nome","slug"}] } ]  só ATIVA e exibirMenu
GET /loja/marcas?destaque=true -> 200 [ { "id","nome","slug","logoUrl" } ]  só ATIVA

GET /loja/produtos?categoria={slug}&subcategoria={slug}&marca={slug}&tipo=DRONE|ACESSORIO
                  &precoMin=&precoMax=&autonomiaMin=&alcanceMin=&nome=&ordem=preco|-preco|nome|lancamento
                  &page=&pageSize=
-> 200 PageResponse de { "id","nome","slug","tipo","marca":{"nome"},"precoMinimo","imagemPrincipal",
                         "disponivel": true|false }
   precoMinimo = menor preço entre as variantes ativas; filtro de preço usa esse valor
GET /loja/filtros?categoria={slug} -> 200 { "marcas": [ {"slug","nome","quantidade"} ],
                                            "preco": { "min", "max" } }
GET /loja/produtos/{slug}
-> 200 { "id","nome","slug","tipo","descricao","marca","subcategoria","garantiaMeses",
         "metaTitle","metaDescription", ...specs (drone) | tipoAcessorio,
         "variantes": [ { "id","nome","sku","preco","disponivel" } ],  (só ativas)
         "midias": [ ... ordenadas ... ] }
-> 404 slug inexistente, RASCUNHO ou INATIVO (RN17)

Rotas públicas que vieram das issues do admin (Fase 1 só com o painel):

GET /loja/produtos/{slug}/compativeis          (acessórios compatíveis, #11)
-> 200 [ { "id", "nome", "slug", "precoMinimo" } ]   só acessórios ATIVO (RN17)
-> 404 slug inexistente ou produto não ATIVO

GET /loja/ofertas (promoções da #14) -> 200 [ { "produto": {...}, "variante": {...}, "precoDe", "precoPor",
                                       "promocao": {"id","nome","dataFim"} } ]
   só promoções vigentes e ativas de escopo PRODUTO, só produtos ATIVO

GET /loja/configuracao   (configuração da #6, só o que a loja mostra)
-> 200 { "prazoArrependimentoDias": 7, "freteReversoPorContaLoja": true }
```
