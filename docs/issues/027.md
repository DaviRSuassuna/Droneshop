### O que entregar

`MercadoPagoClient` (REST Client, `quarkus.rest-client.mercadopago.url`). Pedido tem 1..* pagamentos, um `vigente`. Cartão é aprovado ou recusado na hora; PIX e boleto ficam PENDENTE até o webhook. Webhook atualiza o status com origem INTEGRACAO e, se aprovado: pedido PAGO, reservas CONFIRMADA e movimento SAIDA de origem SISTEMA. No `%test`, a URL aponta para `MercadoPagoFalso` (D34).

API usada do Mercado Pago (é o que o falso imita):
`POST /v1/payments { transaction_amount, payment_method_id: pix|bolbradesco|credit_card|account_money, token, external_reference }` -> `{ id, status: approved|pending|rejected }`.

### Contrato de API

Convenções gerais (paginação, `idXxx`, status `{id, nome}`, erros Problem) em [`docs/API.md`](https://github.com/DaviRSuassuna/droneshop/blob/develop/docs/API.md). Rotas do admin exigem token de administrador com permissão no módulo (#4, #5); rotas `/conta` exigem cliente logado.

```
GET /metodos-pagamento -> 200 [ PIX=1, CARTAO=2, BOLETO=3, FATURAMENTO_PJ=4 ]
GET /status-pagamento   -> 200 [ PENDENTE=1, APROVADO=2, RECUSADO=3, ESTORNADO=4, ESTORNADO_PARCIAL=5 ]

POST /pedidos/{id}/pagamentos   (cliente dono do pedido)
{ "idMetodo": 2, "tokenCartao": "tok_aprovado", "idCartaoSalvo": null, "salvarCartao": false }
-> 200 { "id", "metodo", "status": {"id":2,"nome":"APROVADO"}, "valor", "vigente": true,
         "gatewayTransacaoId" }
   No falso: tokenCartao "tok_recusado" -> RECUSADO; PIX/BOLETO -> PENDENTE
   Nova tentativa: novo registro vigente; o anterior fica vigente = false (RF23)
-> 404 pedido de outro cliente
-> 409 pedido que não está PENDENTE, ou que já tem pagamento APROVADO
-> 400 errors[].field = "idMetodo"  FATURAMENTO_PJ para cliente PF
-> 503 /errors/external-service-unavailable  gateway fora do ar (log de integração, RNF10)

POST /webhooks/mercadopago   (público, chamado pelo gateway)
{ "type": "payment", "data": { "id": "<gatewayTransacaoId>" } }
-> 200   o backend consulta GET /v1/payments/{id} no gateway e aplica o status
   repetir a mesma notificação não duplica nada (idempotente)
GET /pedidos/{id}/pagamentos (admin) e GET /conta/pedidos/{id} trazem os pagamentos
```
