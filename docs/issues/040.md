### O que entregar

Cliente pergunta; loja (admin) ou outros clientes respondem. Pergunta passa por moderação (RN05); resposta da loja sai marcada como oficial.

### Contrato de API

Convenções gerais (paginação, `idXxx`, status `{id, nome}`, erros Problem) em [`docs/API.md`](https://github.com/DaviRSuassuna/droneshop/blob/develop/docs/API.md). Rotas do admin exigem token de administrador com permissão no módulo (#4, #5); rotas `/conta` exigem cliente logado.

```
POST /loja/produtos/{slug}/perguntas (cliente) { "texto": "Funciona com óculos FPV?" } -> 200 PENDENTE
-> 400 errors[].field = "texto"  menos de 10 caracteres
GET /loja/produtos/{slug}/perguntas -> 200 [ só APROVADA, com "respostas": [ { "texto","autor":{"nome"},"oficial" } ] ]
POST /loja/perguntas/{id}/respostas (cliente) { "texto" } -> 200 ; pergunta não aprovada -> 409
GET /admin/perguntas?idStatus= ; PATCH /admin/perguntas/{id} { "idStatus": 2 } -> 204
POST /admin/perguntas/{id}/respostas { "texto" } -> 200 resposta com "oficial": true
```
