### O que entregar

Máquina de estados. Transições permitidas:

| De | Para |
|---|---|
| PENDENTE | PAGO, CANCELADO |
| PAGO | SEPARACAO, CANCELADO |
| SEPARACAO | ENVIADO, CANCELADO |
| ENVIADO | ENTREGUE |
| ENTREGUE | EM_DEVOLUCAO |
| EM_DEVOLUCAO | DEVOLVIDO, ENTREGUE |

Cada transição grava histórico com origem e, quando manual, autor. Transição inválida responde 409 (D30).

### Contrato de API

Convenções gerais (paginação, `idXxx`, status `{id, nome}`, erros Problem) em [`docs/API.md`](https://github.com/DaviRSuassuna/droneshop/blob/develop/docs/API.md). Rotas do admin exigem token de administrador com permissão no módulo (#4, #5); rotas `/conta` exigem cliente logado.

```
PATCH /pedidos/{id}/status
{ "idStatus": 3, "observacao": "Separado no CD" }
-> 204
-> 409 /errors/conflict   transição não permitida (ex.: ENTREGUE -> PAGO)  (D30)
-> 400 errors[].field = "idStatus"   status inexistente
-> 404 pedido inexistente

GET /pedidos/{id}/historico
-> 200 [ { "statusAnterior": {...}, "statusNovo": {...}, "origem": {"id":1,"nome":"MANUAL"},
           "autor": {"id":1,"nome":"Administrador"}, "observacao": "...", "dataCadastro": "..." } ]
   em ordem cronológica; origem SISTEMA/INTEGRACAO vem com "autor": null
```
