### O que entregar

Registro único com dados fiscais, CEP de origem do frete, remetente padrão, prazos de arrependimento, garantia e análise de devolução e frete reverso por conta da loja. A carga de dados cria o registro com os valores do D8 (7 dias de arrependimento, 5 dias úteis de análise, frete reverso pela loja) e 365 dias de garantia.

A rota pública da vitrine (`GET /loja/configuracao`) fica na #21, para a Fase 1 ter só o painel administrativo.

### Contrato de API

Convenções gerais (paginação, `idXxx`, status `{id, nome}`, erros Problem) em [`docs/API.md`](https://github.com/DaviRSuassuna/droneshop/blob/develop/docs/API.md). Rotas do admin exigem token de administrador com permissão no módulo (#4, #5); rotas `/conta` exigem cliente logado.

```
GET /admin/configuracao
-> 200 { "id": 1, "dadosFiscais": "...", "cepOrigemFrete": "77001000",
         "remetentePadrao": "Aeria Drones", "prazoArrependimentoDias": 7,
         "prazoGarantiaDias": 365, "prazoAnaliseDevolucaoDiasUteis": 5,
         "freteReversoPorContaLoja": true }

PUT /admin/configuracao   (mesmo corpo, sem id)
-> 204
-> 400 errors[].field = "cepOrigemFrete"            não tem 8 dígitos
-> 400 errors[].field = "prazoArrependimentoDias"   menor que 7 (piso do CDC, D8)
-> 400 errors[].field = "prazoGarantiaDias"         menor que 1

Não existe POST nem DELETE: as duas respondem 405.
```
