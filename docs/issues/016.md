### O que entregar

Entidades `Pedido`, `ItemPedido` e `EnderecoPedido` (embutido). Listagem e detalhe no admin, alimentados pela carga de dados até o checkout existir (D19). Blocos de pagamento e entrega da tela de detalhe ficam vazios até as fases seguintes.

Carga de dados: o `import.sql` cria o cliente semente `cliente@aeria.com.br` / `aeria123` (perfil de cliente com um endereço) e **três pedidos em cada status** (24 pedidos; os testes de outras issues mudam alguns de status). Os itens desses pedidos são de **acessórios**, para que a regra de número de série da #34 não trave as transições da carga. Todos os pedidos da carga são do cliente semente, com histórico de status coerente; os ENTREGUE foram entregues **há 60 dias** (data da transição para ENTREGUE no histórico), o que a #37 usa para testar o prazo de arrependimento, com itens de produtos da carga. Se a #19 ainda não estiver feita, esta issue cria a entidade `PerfilCliente` só com os campos do diagrama (sem rotas); a #19 completa.

### Contrato de API

Convenções gerais (paginação, `idXxx`, status `{id, nome}`, erros Problem) em [`docs/API.md`](https://github.com/DaviRSuassuna/droneshop/blob/develop/docs/API.md). Rotas do admin exigem token de administrador com permissão no módulo (#4, #5); rotas `/conta` exigem cliente logado.

```
GET /status-pedido -> 200 [ PENDENTE=1, PAGO=2, SEPARACAO=3, ENVIADO=4, ENTREGUE=5,
                                EM_DEVOLUCAO=6, DEVOLVIDO=7, CANCELADO=8 ]

GET /pedidos?idStatus=&dataInicio=2026-10-01&dataFim=2026-10-31&busca=&page=&pageSize=
-> 200 PageResponse de { "id", "numero": "AER-000001", "status": {...}, "cliente": {"id","nome"},
                         "valorTotal", "quantidadeItens", "dataCadastro" }
   busca: número do pedido ou nome do cliente; datas sobre dataCadastro (inclusivas)
GET /pedidos/resumo-status -> 200 [ { "status": {...}, "quantidade": 3 } x 8 ]

GET /pedidos/{id}
-> 200 { "id", "numero", "status", "cliente": {...}, "valorTotal", "valorFrete", "valorDesconto",
         "itens": [ { "id", "produto": {"id","sku","nome"},
                      "quantidade", "precoUnitarioCongelado", "subtotal" } ],
         "enderecoEntrega": { "destinatario", "logradouro", "numero", "complemento",
                              "bairro", "cidade", "uf", "cep" },
         "pagamentos": [], "entrega": null }
-> 404

Pedido não tem POST/PUT/DELETE nesta issue (405).
```
