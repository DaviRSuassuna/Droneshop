### O que entregar

Mídias do produto com `tipo` (IMAGEM, VIDEO, MANUAL_PDF), `url`, `principal`, `ordem`, `altText`. Imagem e PDF por upload, vídeo por URL (D29). Arquivos gravados em `aeria.midias.diretorio` e servidos em `/midias/arquivos/{nome}`.

### Contrato de API

Convenções gerais (paginação, `idXxx`, status `{id, nome}`, erros Problem) em [`docs/API.md`](https://github.com/DaviRSuassuna/droneshop/blob/develop/docs/API.md). Rotas do admin exigem token de administrador com permissão no módulo (#4, #5); rotas `/conta` exigem cliente logado.

```
GET /tipos-midia -> 200 [ {"id":1,"nome":"IMAGEM"}, {"id":2,"nome":"VIDEO"}, {"id":3,"nome":"MANUAL_PDF"} ]

POST /produtos/{id}/midias   multipart/form-data
   idTipo=1, arquivo=<png|jpg>, altText="Drone de frente", principal=true
   idTipo=3, arquivo=<pdf>
   idTipo=2, url="https://www.youtube.com/watch?v=..."
-> 200 { "id": 5, "tipo": {"id":1,"nome":"IMAGEM"}, "url": "/midias/arquivos/<nome>.png",
         "principal": true, "ordem": 1, "altText": "..." }
-> 400 errors[].field = "altText"   imagem sem texto alternativo (RNF08)
-> 400 errors[].field = "arquivo"   tipo de arquivo diferente do idTipo, ou acima de 20 MB
-> 400 errors[].field = "url"       vídeo sem URL
-> 404 produto inexistente

GET /produtos/{id}/midias  -> 200 [ ... ] ordenado por "ordem"
PATCH /midias/{id}  { "principal": true } | { "ordem": 3 } | { "altText": "..." } -> 204 | 404
   marcar uma como principal desmarca a anterior (só uma principal por produto)
PATCH /produtos/{id}/midias/ordem  { "ids": [7, 5, 6] } -> 204   reordena
DELETE /midias/{id} -> 204 | 404   (apaga o arquivo do disco)
GET /midias/arquivos/{nome} (público) -> 200 com o content-type do arquivo | 404
```
